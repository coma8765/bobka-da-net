# ЛР6: консольный клиент PostgreSQL

Python 3 и Psycopg 3, raw SQL без ORM. Реализованы все десять операций
из [RFC](docs/RFC.md): запросы, метаданные, функции и процедура ЛР3,
создание таблицы заметок и вставка данных.

## Подготовка и запуск

Нужна запущенная PostgreSQL 17 с базой `supply_lab`, схемой и данными ЛР1,
а также объектами ЛР3: `public.fn_delivery_total(bigint)`,
`public.fn_supplier_deliveries(bigint)`, `public.sp_describe_table(text, jsonb)`.
Клиент не устанавливает и не изменяет объекты предыдущих лабораторных.

Из папки `lr6`:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
export PGPASSWORD=postgres
.venv/bin/python -m src.cli
```

Из родительской папки также поддерживается запуск:

```bash
python3 -m pip install -r lr6/requirements.txt
export PGPASSWORD=postgres
python3 -m lr6.src.cli
```

Настройки подключения задаются переменными `PGHOST` (по умолчанию
`127.0.0.1`), `PGPORT` (`55432`), `PGDATABASE` (`supply_lab`), `PGUSER`
(`postgres`). Пароль читается драйвером из `PGPASSWORD` либо `.pgpass`;
для стандартного учебного окружения установите `PGPASSWORD=postgres`, как
в примере выше. Пароль в исходном коде не хранится. Подключение к другой
базе отклоняется. Ожидание подключения ограничено пятью секундами.

## Работа с меню

Пункты `1`–`10` соответствуют RFC; `0`, Ctrl+C или конец ввода завершают
приложение. Для рейтинга введите даты начала и конца в формате
`ГГГГ-ММ-ДД`: конечная дата не включается в период. Рейтинг показывает всех
поставщиков с поставками за период; доли вычисляются без округления в SQL.
При нулевой общей стоимости доля отображается как `NULL`.

В пункте 2 лимит задаётся от 1 до 100. Пункт 6 выводит не более 100 последних
поставок выбранного поставщика. Для заметок сначала выполните пункт 9,
затем пункт 10. Успешные DDL/DML фиксируются, ошибка откатывает команду.
Сообщения сервера печатаются в консоли, после ошибки запроса меню продолжает
работать; при потере соединения приложение завершает работу.

## Запуск всех пунктов без ввода

Из папки `lr6`:

```bash
PGPASSWORD=postgres .venv/bin/python run_all.py
```

Скрипт выполняет пункты 1–10 и печатает заголовок и результат каждого
в stdout. Для примеров выбираются последняя поставка, её поставщик и день
этой поставки; в пункте 2 выводятся пять последних поставок. Пункт 9 создаёт
таблицу заметок, пункт 10 сохраняет одну демонстрационную заметку за запуск.
При ошибке пункта скрипт продолжает выполнение и возвращает код 1.

Для демонстрации с итоговым откатом и сохранением вывода в файл:

```bash
PGPASSWORD=postgres .venv/bin/python run_all.py --rollback > results.txt
```

## Тесты

Из папки `lr6` с настроенным подключением:

```bash
export PGPASSWORD=postgres
.venv/bin/python -m unittest discover -s tests -v
```

Только проверки консольного интерфейса и валидации, без базы:

```bash
.venv/bin/python -m unittest tests.test_cli tests.test_db -v
```

Команда из RFC, выполняемая из родительской папки:

```bash
python3 -m unittest lr6/tests/test_queries.py
```

Интеграционные тесты требуют непустой `supply_lab` и объектов ЛР3.
Отсутствующие зависимости считаются ошибкой, тесты не пропускаются.
Проверяются все десять операций, ограничения, параметризация,
восстановление после ошибки, отсутствие незавершённых транзакций и откат.
DDL/DML тестов выполняются внутри внешних транзакций с итоговым `ROLLBACK`:
тестовые заметки и созданные тестами таблицы не сохраняются. Если таблица
заметок уже существовала, её sequence может продвинуться: PostgreSQL
не откатывает выданные значения identity.
